# **App Name**: Node Weaver

## Core Features:

- Node Display: Display nodes as floating elements in the center of the screen.
- Node Creation Button: Button to trigger the node creation process, opening an attribute selection window.
- Attribute Definition: Attribute selection window to define specifics for each new node.

## Style Guidelines:

- Vertical screen layout optimized for portrait mode.
- Background color: Dark gray (#333333) to make the floating nodes stand out.
- Node color: Soft blue (#ADD8E6) for a calming visual effect.
- Accent: Teal (#008080) for interactive elements like buttons and selected node attributes.
- Simple, modern icons for node attributes and button actions.
- Smooth transitions and animations when nodes are created or attributes are modified.
